# ASTRO3301

Hello Exoplaneteers, welcome to learning data analysis in Python for Astronomy 3301!
In this repository you will find Jupyter notebooks that will guide you through the basics of data analysis in Python.
This is meant to give you the computational tools you will need to begin conducting astronomical research.

This repository is heavily inspired and pulls content from the [Python Bootcamp]((https://github.com/shockblack/Python_Bootcamp)) for the Cornell Department of Astronomy REU program by Aiden Zelakiewicz.
